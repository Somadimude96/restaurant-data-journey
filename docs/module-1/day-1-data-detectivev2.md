# Module 1 Day 1: Data Detective

## Exercise purpose

The purpose of this exercise was to classify different examples of data by data type, structure and likely format or medium.

## My completed classification

|---|---|---|---|---|
| Data example | Classification | Structure | Likely format / medium |
|---|---|---|---|
| Restaurant transaction table | CSV | Structured | AdRows and columns with defined fields |
| Customer review written online | Qualitative, unstructured | Free text describing their experience 
| JSON order response from a delivery application | Semi-structured, Json | Keys and values, not always a fixable table
| Menu price | Quantitative | unstructured| Measurable value|
| Photograph of a meal | Qualitative | unstructured | PNG, JPEG|
| Restaurant branch name | Qualitative| Structured | Text database field |
| Number of orders each day | Quantitative | Structured | Excel or CSV |
| Spreadsheet containing employee shifts | Mixed (qualitative and quantitative) | Mixed | Excel / CSV spreadsheet |
| Audio recording of a customer-support call | Qualitative | unstructured| MP3 / WAV audio file |
| Payment method | Qualitative | Structured|Text / database field
